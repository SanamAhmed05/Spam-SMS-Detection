# 📩 SMS Spam Detection using Machine Learning

## 📌 Project Overview
This project is a Machine Learning-based SMS Spam Detection application that classifies SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP). The application is deployed with Streamlit for an interactive web interface.

## 🚀 Features
- Detects Spam and Ham SMS messages
- Text preprocessing using NLTK
- TF-IDF Vectorization
- Multinomial Naive Bayes Classifier
- Interactive Streamlit Web App
- Fast and accurate predictions

## 📂 Dataset
- Dataset: SMS Spam Collection Dataset
- Total Messages: 5,572
- After Removing Duplicates: 5,169

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Streamlit

## 📊 Model Performance
- Accuracy: **97.10%**
- Precision: **100%**
- Recall: **78%**
- F1-Score: **88%**
